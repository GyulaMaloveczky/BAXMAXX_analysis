# Scripts

Helper scripts for bookkeeping and small numerical utilities.

## Included utilities

- `atom_counter.py` — counts atom classes in a PDB chain
- `atom_summer.py` — sums atom counts across PDBs
- `delta_G_calc.py` — converts affinity values into free-energy estimates

## Usage

These utilities are intended to be reused from the analysis notebooks rather than being treated as standalone project entry points.
